# Kali Setup

Kali is treated as a local execution environment, not a remote service. Install Node using Kali's approved package workflow, run `npm install`, then run the commands in the README. The `KaliExecutionEnvironment` currently only identifies an allowlisted Linux local-process policy; it has not been tested on a Kali system. Do not report Kali support as verified until the CLI persistence, protocol, and allowlisted process tests run on an actual Kali target.
